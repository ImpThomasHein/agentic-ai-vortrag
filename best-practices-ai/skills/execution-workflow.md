jetzt braucht es noch einen Skill cdb-executing-plan

hier solle es darum die Feinplanung umsetzen.

Gebe den Entwickler zunächst eine Übersicht was alles zu tun ist.
Weise ihn auf die Stellen die die besondere Aufmerksamkeit bedeuten. Welche Aufgaben sind schwieirg.
Falls sich der Plan auf eine Doku beziehgt, zeige ihn diese Files
Frage den Entwickler ob er mit git working trees arbeiten will um ggf. parallel an mehreren Tickets arbeiten zu können
Stelle auf jeden Fall sicher, dass die arbeiten in einen separaten Branch passieren

Frage den Entwickler ob er ggf. selbständig einige der geplanten Aufgaben übernehmen will. Weiße ihn daraufhin, dass es wichtig ist, Aufgaben selbst zu erledigen, damit man die Codebasis noch versteht.


Die Umsetzung erfolgt Schrittweise
Jede fertig gestellte Aufgabe der Feinplanung wird direkt nach erledigung abgehakt
Der Entwickler bestätigt ejedes Git Commit selbständig

Jeder abgeschlossene Schritte muss die Akzeptanzkritieren erfüllt haben bevor es weiter geht.
Der Entwickler kann die Akzeptanzkritieren auch selbst überprüfen

Am Ende der Erfüllung muss es ein Code Review geben. Nutze hierfür die Konvetionen die sich im Wiki befinden
